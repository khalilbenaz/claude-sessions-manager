## Français (fr-FR)

**Description**

Claude Sessions Manager réunit toutes vos sessions Claude Code dans une seule fenêtre, au lieu d'une pile d'onglets de terminal.

• Voyez en direct quelle session travaille, laquelle attend votre réponse et laquelle a fini — avec notification et son.
• Fermez la fenêtre : vos sessions continuent en arrière-plan et reviennent même après un redémarrage de l'ordinateur.
• Suivez jusqu'à 4 sessions côte à côte.
• Faites travailler plusieurs Claude sur le même dépôt sans conflit grâce aux worktrees git, puis fusionnez en un clic.
• Relisez les fichiers modifiés, le diff et committez depuis le panneau Modifications.
• Retrouvez toutes vos conversations dans l'historique, reprenez-les en un clic.
• Palette de commandes (Ctrl+K), recherche dans toutes les sessions, file d'attente de prompts, bibliothèque de prompts, modèles de session.
• Verrouillez une session sensible par mot de passe.
• Rendez une session accessible depuis l'app Claude sur votre téléphone (Remote Control de Claude Code).
• Consommation de tokens et coût estimé, chronologie des actions, export Markdown / PDF.
• Thème clair / sombre automatique, français et anglais.

Chaque session est un vrai Claude Code : vos réglages, hooks, serveurs MCP et commandes sont conservés. Tout reste sur votre ordinateur : serveur local uniquement, aucune télémétrie.

Nécessite Claude Code, installé séparément (https://docs.claude.com/claude-code). Projet libre et indépendant (licence MIT), non affilié à Anthropic.

## English (en-US)

**Description**

Claude Sessions Manager brings all your Claude Code sessions into a single window instead of a pile of terminal tabs.

• See live which session is working, which one is waiting for you and which one is done — with notifications and sound.
• Close the window: your sessions keep running in the background and come back even after a reboot.
• Follow up to 4 sessions side by side.
• Let several Claudes work on the same repository without conflicts thanks to git worktrees, then merge in one click.
• Review changed files, diffs and commit from the Changes panel.
• Find every conversation in the history and resume it in one click.
• Command palette (Ctrl+K), search across sessions, prompt queue, prompt library, session templates.
• Lock a sensitive session with a password.
• Make a session available in the Claude mobile app (Claude Code Remote Control).
• Token usage and estimated cost, action timeline, Markdown / PDF export.
• Automatic light / dark theme, English and French.

Each session is a real Claude Code: your settings, hooks, MCP servers and commands are kept. Everything stays on your computer: local server only, no telemetry.

Requires Claude Code, installed separately (https://docs.claude.com/claude-code). Free, independent open-source project (MIT license), not affiliated with Anthropic.

**Product features**
- Many Claude Code sessions in one window
- Live status and notifications
- Persistent sessions, resumed after reboot
- Split view up to 4 sessions
- Git worktrees and Changes panel
- Conversation history and resume
- Command palette and search
- Prompt queue and prompt library
- Password lock
- Access from the Claude mobile app

**Keywords**: Claude, Claude Code, AI, terminal, sessions, developer, git, worktree

> Desktop app (runFullTrust, Electron) that runs the Claude Code command-line tool, installed separately by the user (https://docs.claude.com/claude-code), in embedded terminals. It starts a local server bound to 127.0.0.1 only (not reachable from the network) and collects no telemetry.
