              Mémoire des sessions : laquelle utiliser ?

              Tes autres machines utilisent claude-mem.

              Une seule mémoire à la fois, seulement pour les sessions lancées par l'app. Avec la synchro, le même choix s'applique à toutes les machines.

              Si Claude compacte la conversation en boucle, c'est souvent une fenêtre trop petite imposée par CLAUDE_CODE_AUTO_COMPACT_WINDOW : « Fenêtre complète » la remplace pour les sessions de l'app.

              Remote Control de Claude Code : la session apparaît dans l'app Claude (onglet Code) et sur claude.ai/code. Connexion sortante via Anthropic, aucun port ouvert ; le code reste sur ce PC. Nécessite un abonnement Pro, Max, Team ou Enterprise connecté avec /login (pas une clé API).

                      Créer une extension : le format

                      Retrouve tes sessions (nom, dossier, modèle, groupe) et leurs conversations sur tes autres machines. Les conversations sont chiffrées avec ton code avant l’envoi : le serveur ne peut pas les lire. Seules les machines qui partagent le même code se voient.

                      Première machine : crée un code, puis saisis-le sur tes autres machines.

                      J'ai déjà un code (créé sur une autre machine) :

                      Saisis ce code sur tes autres machines (Réglages › Synchronisation › J'ai déjà un code). Ne le partage avec personne d'autre : qui a le code voit tes sessions.

                        Configuration de Claude (chiffrée, la plus récente gagne)

                        Un fichier remplacé ou supprimé sur cette machine est d'abord copié dans le dossier de données de l'app (claude-sync-backup, gardé 30 jours). Jamais d'écriture à travers un lien ni hors de ~/.claude. Les skills installées par des plugins ne sont pas concernées.

                        Fichiers reçus

                          Derniers changements reçus (avec la copie de la version remplacée) :

                            Machines

                              « Retirer » enlève une machine de la liste, mais elle garde le code : pour lui couper vraiment l'accès, change de code. L'ancien espace est alors effacé du serveur, et tu saisis le nouveau code sur tes autres machines.

                              Ce que tu modifies sur cette machine part tout de suite ; l'intervalle règle la récupération des changements des autres machines. « Synchroniser maintenant » reste disponible.

                              Avancé

                              Le dossier personnel est reconnu tout seul ({home}). Déclare le même alias sur chaque machine pour les dossiers rangés ailleurs (ex. code=D:\dev sur le PC, code=~/dev sur le Mac).

                              Vide = serveur par défaut. Pour héberger le tien, voir sync-worker/ dans le dépôt.
