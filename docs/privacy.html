Claude Sessions

Privacy Policy

Last updated: September 25, 2026

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

What Claude Sessions does

Claude Sessions is a desktop application that runs several Claude Code sessions in one window. It starts a small server on your computer that is bound to 127.0.0.1 only: it cannot be reached from the network or from other computers.

Data collected

None. Claude Sessions has no telemetry, no analytics, no crash reporting, no advertising and no user account. It does not send anything to its author or to any third party.

Data stored on your computer

  • The list of open sessions (name, working folder, model, conversation identifier), a random access token and a log file, in %APPDATA%\claude-sessions (Windows) or ~/Library/Application Support/claude-sessions (macOS).
  • Copies of images or files you drop or paste into a session, in your system temporary folder; they are deleted automatically after 7 days.
  • The conversation history shown in the app is read from Claude Code's own files (~/.claude/projects); Claude Sessions only reads it, except for writing the session name when you rename a session.

Uninstalling the application does not delete these files; you can remove the folders above at any time.

Network traffic

The only network traffic comes from the Claude Code sessions you start: Claude Code communicates with Anthropic's API exactly as it does in a terminal, under Anthropic's privacy policy. When you open a link from a session, it opens in your default web browser. The project website may query the public GitHub API to show the latest download links.

Questions or concerns: open an issue on GitHub.

Politique de confidentialité

Dernière mise à jour : 25 septembre 2026

Ce programme ne transmet aucune information à d'autres systèmes en réseau, sauf à la demande expresse de l'utilisateur ou de la personne qui l'installe ou l'utilise.

Données collectées

Aucune. Pas de télémétrie, pas de statistiques, pas de rapport de plantage, pas de publicité, pas de compte. Rien n'est envoyé à l'auteur ni à un tiers.

Données enregistrées sur votre ordinateur

  • La liste des sessions ouvertes (nom, dossier, modèle, identifiant de conversation), un jeton d'accès aléatoire et un journal, dans %APPDATA%\claude-sessions (Windows) ou ~/Library/Application Support/claude-sessions (macOS).
  • Les copies des images ou fichiers déposés dans une session, dans le dossier temporaire du système, effacées automatiquement après 7 jours.
  • L'historique affiché est lu dans les fichiers de Claude Code (~/.claude/projects) ; seul le nom d'une session renommée y est écrit.

Trafic réseau

Le serveur local n'écoute que sur 127.0.0.1. Le seul trafic réseau est celui des sessions Claude Code que vous lancez, qui communiquent avec l'API d'Anthropic comme dans un terminal.
