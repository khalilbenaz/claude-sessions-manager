Tout ce qu'il faut pour travailler en parallèle

Chaque session est un vrai Claude Code, avec vos réglages, vos hooks et vos commandes. Claude Sessions ne fait que les réunir et les garder en vie.

🟢État en direct

Orange quand Claude travaille, rouge quand il attend votre réponse, vert quand c'est fini. Notification, son, rappels et pastille sur l'icône.

⊞Vue partagée

Suivez 2 à 4 sessions côte à côte. Glissez une session sur un panneau, passez de l'un à l'autre au clavier.

⎇Un worktree par session

Faites travailler plusieurs Claude sur le même dépôt sans conflit : chaque session a sa branche, fusion en un clic.

±Panneau Modifications

Fichiers modifiés, diff coloré, annuler un fichier, commit avec message proposé — sans quitter l'app.

♻️Sessions persistantes

Fermer la fenêtre ne coupe rien. Après un redémarrage de l'ordinateur, chaque session revient avec sa conversation.

⌘Palette de commandes

Ctrl/⌘+K : sessions, conversations, modèles, prompts et actions, en quelques lettres.

⏳File d'attente et prompts

Enchaînez des demandes qui partent quand Claude a fini, réutilisez vos prompts, envoyez-en un à plusieurs sessions.

💰Consommation et chronologie

Tokens et coût estimé par session et par jour, liste des fichiers lus et modifiés, export Markdown / PDF.

↪️Ramener vos terminaux

Les sessions Claude ouvertes dans des terminaux apparaissent dans l'app : déplacez-les ou copiez-les.

🖼️Images et fichiers

Glissez-déposez ou collez une capture : elle est jointe à votre message comme dans un terminal.

🗂️Groupes et modèles

Rangez vos sessions par projet, épinglez-les, lancez un modèle (dossier, modèle, worktree, premier prompt) en un clic.

📱Depuis votre téléphone

Une case suffit : la session devient pilotable depuis l'app Claude et claude.ai/code (Remote Control de Claude Code), sans port ouvert.

🔒Verrouillage par mot de passe

Masquez une session sensible : elle continue de tourner, mais son contenu et sa saisie restent bloqués jusqu'au mot de passe.

🔔Zone de notification

Réduisez l'app près de l'horloge : liste des sessions et de leur état au clic droit, point rouge quand l'une vous attend.

◐Thème automatique

Clair ou sombre selon Windows / macOS, en direct — ou forcé. Interface en français ou en anglais.

🔄Mises à jour automatiques

Nouvelle version téléchargée en arrière-plan ; un redémarrage l'installe et vos sessions reviennent seules.

Télécharger

Seul prérequis : Claude Code installé (la commande claude). Node.js n'est pas nécessaire.

SystèmeFichierInstallation
Windows 10 / 11Claude-Sessions-Setup.exeDouble-clic. Installation en un clic, sans droits administrateur.
Mac Apple Silicon (M1…M4)Claude-Sessions-arm64.dmgOuvrir, glisser dans Applications.
Mac IntelClaude-Sessions-x64.dmgOuvrir, glisser dans Applications.
Premier lancement. L'application n'est pas encore signée par un certificat éditeur :
Windows : « Windows a protégé votre ordinateur » → Informations complémentaires → Exécuter quand même.
macOS : clic droit sur l'app → Ouvrir → Ouvrir (ou xattr -cr "/Applications/Claude Sessions.app").

Ou en ligne de commande

git clone https://github.com/khalilbenaz/claude-sessions-manager.git
cd claude-sessions-manager
npm ci && npm install -g .
csm install        # démarrage automatique + raccourci
csm                # ouvre la fenêtre

Local, isolé, sans télémétrie

Vos sessions ne quittent pas votre machine : seul Claude Code lui-même parle à l'API d'Anthropic, comme d'habitude.

🔒Serveur local uniquement

Écoute sur 127.0.0.1, jeton aléatoire exigé, contrôle de l'en-tête Host contre le DNS rebinding.

🧱Fenêtre isolée

Isolation de contexte et bac à sable, aucun accès Node côté page, navigation verrouillée, permissions limitées aux notifications et au presse-papiers.

🛡️CSP stricte

Aucun script inline ni ressource externe ; les liens externes s'ouvrent dans votre navigateur.

📦Builds publics

Les installeurs sont construits par GitHub Actions à partir du code publié, jamais sur un poste.

Questions

Que devient une session quand je quitte l'app ?

Elle continue de tourner. « Quitter et arrêter toutes les sessions » les arrête ; elles reviendront au prochain lancement.

Mes réglages Claude Code sont-ils conservés ?

Oui : chaque session lance votre claude habituel, avec votre configuration, vos hooks et vos serveurs MCP.

Est-ce un produit Anthropic ?

Non. Projet libre et indépendant. « Claude » et « Claude Code » sont des marques d'Anthropic.
